# Current Problems

## Infrastructure

* Development and production environments are not separated.
* Container configurations are managed manually.
* Docker-based deployment is not standardized.

## Operations

* Monitoring system is not implemented.
* Backup strategy is not fully designed.
* Operational procedures are not documented.

## Storage

* Multiple services depend on the same storage mount.
* Storage redundancy is limited.

## Network

* Service management is based on direct IP access.
* Reverse proxy and centralized routing are not implemented.
